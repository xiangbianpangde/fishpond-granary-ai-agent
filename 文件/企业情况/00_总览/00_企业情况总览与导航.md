## 4. 通用书写规则

1. 每个文件标注：状态、责任人、来源/证据等级、最后更新时间。
2. 任何未确认的结论都标 `[猜测]` 或 `[假设]`，并指明依赖的证据闸门。
3. 设备接口 / 软件接口 / 监管接口分开记录；通道 B 输入与 B+ 输入分开记录。
4. 行业资料不直接来自项目方时，仅作为参照，写明“行业共性 / 项目方特异性”。
5. 任何阶段复盘都遵循：发生了什么 → 决策 → 影响 → 风险 → 下一步。
