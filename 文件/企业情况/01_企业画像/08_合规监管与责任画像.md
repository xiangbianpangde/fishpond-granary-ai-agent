## 1. 权责链

```text
政府监管责任（粮食主管部门）
    ↓
企业保管责任（项目方）
    ↓
仓库/基地负责人
    ↓
设备操作责任（保管员 / 操作员 / 设备运维）
    ↓
AI Agent 建议责任（边界与限制）
```

## 2. AI 权限等级

| Level | 含义 | Demo 取值 |
|---|---|---|
| Level 0 | 只展示 | ✓ |
| Level 1 | 提醒 / 研判 | ✓ |
| Level 2 | 建议 | ✓（粮库高风险默认上限） |
| Level 3 | 人工确认执行 | ✓（渔业白名单场景可演示） |
| Level 4 | 授权自动执行 | ✗（Demo 不进入） |

> **Demo 原则**：不进入 Level 4；任何高风险动作必须人工确认。

## 5. Demo → Pilot Gate（v0.3 新增 · Sol P0-3）

> **目的**：明确 Demo 不等于 Pilot，必须满足以下全部条件才允许 Pilot 启动。
> **关键原因**：政府和粮库场景能否推进，取决于这条闸门是否被严格守住。

| 条件 | Demo | Pilot | 当前状态 | 责任人 | 关闭条件 |
|---|---|---|---|---|---|
| **数据** | 模拟 / 脱敏 / 回放 | 真实连续（≥ 7 天） | `[猜测]` 仅回放 | 数据工程师 | 取得连续 ≥ 7 天的真实数据 |
| **责任人** | 确定联系人 | 签字责任链 | `[猜测]` 仅有联系人 | 项目经理 | 五主体组织关系矩阵签字 |
| **权限** | 只读 | 授权接口 + 写权限 | `[猜测]` 仅只读 | IoT 工程师 | 取得写权限 + 原系统厂商授权 |
| **安全** | 人工确认 | 原硬联锁 + SOP 联动 | `[猜测]` 仅人工确认 | 安全工程师 | 原硬联锁独立性测试通过 |
| **监管字段** | 字段映射草案 | 监管单位确认字段 + 报送授权 | `[猜测]` 仅草案 | 安全合规负责人 | 监管单位书面确认 |
| **SOP** | 知识库框架 + 占位 | 正式 SOP + 提供人授权 | `[猜测]` 仅框架 | 业务分析师 | 正式 SOP 文本 + 授权书 |
| **验收指标** | Demo 场景通过率 | Pilot KPI 签字 | 待补 | 项目经理 + 技术负责人 | Pilot KPI 双方签字 |

### 5.1 Pilot 准入条件（强约束）

> 以下条件必须**全部满足**，否则 Pilot 不得启动：

1. **企业主体确认** —— 营业主体 / 法人 / 粮库经营权 / 政府授权全部达到 E2（见 `01_企业基本画像.md` §3）；
2. **数据接口确认** —— 至少一个真实只读接口 + 一个回放接口通过 E4 验证（见 `05_技术系统画像.md` / `06_数据资产画像.md`）；
3. **责任链签署** —— 五主体组织关系矩阵签字（见 `03_组织与决策链画像.md` §3）；
4. **安全评估** —— Q1 原硬联锁独立性测试 + 通道 B 拓扑确认 + Safety Rule fail-closed 验证通过（见 `01_Demo_PRD.md` §9.4.1）；
5. **连续运行数据** —— 至少连续 7 天真实数据可用于 Demo 重现；
6. **验收指标** —— Pilot KPI 双方签字，含 ROI 与降级指标（见 `09_AI价值机会画像.md` §3）。

## 6. 事件 × 最终责任（v0.3 新增 · Sol P0-2）

| 事件类型 | 最终责任主体 | 备注 |
|---|---|---|
| AI 误报导致人工误操作 | 项目方 + 企业审核人 | AI 不能独立决策 |
| 人工未按 AI 建议确认 | 企业 | 责任仍在人 |
| 监管报送数据错误 | 企业审核人 + 上级 | AI 仅生成字段草案 |
| 通道 B 独立触发安全动作 | 原系统维护方 + 企业 | AI 不参与原硬联锁 |
| 政策合规违规 | 政府监管单位 | 政策合规不可让渡 |

|---|---|---|---|
| 数据采集与展示 | ✓ | | |

| 监管报送字段生成 | ✓（L0/L1） | ✓（人工确认） | ✓（接收方） |
| 监管检查与稽核 | | ✓（保管员 / 上级） | ✓（粮食主管部门） |

## 8. 升级为已确认的条件

- 取得监管字段规范 → 替换 §4；
- 取得应急 SOP 文本 → 替换 §4；
- 取得权责清单（监管 / 企业 / 责任人）→ 替换 §1 与 §6；
- 取得保密协议模板 → 替换 §3 / §4 保密要求；
- §5 Pilot Gate 七项条件全部满足 → 才允许进入 Pilot 启动流程。
