## 2. 一句话定位

`[猜测/E1]` 项目方同时持有 **智慧渔业基地**（连片规模化、标准化水产养殖基地，以蟹为主）和 **县级储备粮库** 两类异构农业资产，已部署 IoT 与基础信息化系统，但 AI 中枢尚未建立，目标是先做 Demo 验证"AI Agent 在农业 + 国家储备资产"场景下的可行性。

## 3. 双业务域统一模型

```text
农业资产
├── 生命资产（水产养殖 / 蟹）
│     └── 主体：智慧渔业基地
└── 国家保障资产（粮食储备）
      └── 主体：县级储备粮库

共同能力：感知 → 预测 → 异常检测 → SOP 执行 → 人工授权
```

| 维度 | 智慧渔业（生命资产） | 县级储备粮库（国家保障资产） |
|---|---|---|
| 业务目标 | 赚钱、降本增效 | 监管、保障、应急 |
| 核心流程 | 投喂 → 调控 → 病害防控 → 数据归集 | 粮情监测 → 通风/气调 → 出入库 → 监管报送 |
| 决策窗口 | 分钟级（低氧/设备联动） | 小时–天级（通风/气调），安防/熏蒸秒级 |
| 合规边界 | 用药规范、防疫 | 县级储备粮监管、保密 |
| Agent 责任边界 | L2（白名单场景可演示 L3） | L1（只研判，不执行熏蒸/门禁控制） |

### 5.1 事件 × 最终责任（v0.3 新增 · Sol 建议）

| 事件类型 | 最终责任主体 |
|---|---|
| AI 误报导致人工误操作 | 项目方 + 企业审核人 |
| 人工未按 AI 建议确认 | 企业 |
| 监管报送数据错误 | 企业审核人 + 上级 |
| 通道 B 独立触发安全动作 | 原系统维护方 + 企业 |
| 政策合规违规 | 政府监管单位 |

> **原则**：任何 AI 路径（A / B+）故障都不能影响通道 B（原硬联锁）的独立触发；详见 `01_Demo_PRD.md` §9.3。

## 7. Pilot Gate（v0.3 新增 · Sol P0-3）

> **Demo 阶段不进入 Pilot**；必须满足以下全部条件才允许 Pilot 启动。

| 条件 | Demo | Pilot |
|---|---|---|
| 数据 | 模拟 / 脱敏 / 回放 | 真实连续（≥ 7 天） |
| 责任人 | 确定联系人 | 签字责任链 |
| 权限 | 只读 | 授权接口 + 写权限 |
| 安全 | 人工确认 | 原硬联锁 + SOP 联动 |
| 监管字段 | 字段映射草案 | 监管单位确认字段 + 报送授权 |
| SOP | 知识库框架 + 占位 | 正式 SOP + 提供人授权 |
| 验收指标 | Demo 场景通过率 | Pilot KPI 签字 |

> Pilot Gate 是政府 / 粮库场景能否推进的关键；详见 [08_合规监管与责任画像.md](08_合规监管与责任画像.md) §5。
