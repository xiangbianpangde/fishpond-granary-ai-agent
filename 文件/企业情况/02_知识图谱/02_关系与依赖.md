## 3. 关键依赖关系（猜想）

> 这一节是猜测性结论，未确认前必须标 `[猜测]`。

1. `夜间溶氧骤降` 痛点 ← 多源数据可信度 + 设备控制权限；
2. `蟹病诊断` 痛点 ← SOP + 病例库 + 资深经验文档化；
3. `熏蒸期人员误入` 痛点 ← 原硬联锁独立性 + 门禁/视频只读 + Q7 授权；
4. `粮情研判` 痛点 ← 老旧仓房漂移评估 + 连续历史数据 + 主数据治理；
5. `监管报送` 合规 ← 县级储备粮监管字段 + 报送频率 + 授权；
6. `知识库` ← SOP/病例/预案的提供人和版本。
