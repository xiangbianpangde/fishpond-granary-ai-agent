## 1. 方案总纲

一句话：**一个共用底座 + 两条场景链路 + 三种数据模式（回放 / Simulator / 真实）+ 双态安全设计**。

```text
┌────────────────────────── 共用底座（9 条 P0-BASE 承载）──────────────────────────┐
│  COMMON-INT-001 数据适配层：Mock / Replay / Simulator / Real 四模式统一接入      │
│  COMMON-AGT-001 Agent 决策编排中枢（LLM）＋ COMMON-AGT-003 Tool Calling 封装     │
│  COMMON-SAF-001 Safety Rule Engine ＋ SAF-002 模块化权限隔离 ＋ SAF-003 强制降级 │
│  COMMON-NFR-001 全流程审计日志 ＋ NFR-002 可解释输出 ＋ NFR-003 SLA 超时降级     │
└──────────────┬───────────────────────────────────────────┬──────────────┘
               ▼                                           ▼
   场景 A · 夜间低氧（渔业·通道 A）              场景 B · 熏蒸误入（粮库·L1+B+）
   ALG 时序异常 → AGT 策略 → 校验 → 控制        CV 检测 → AGT 风险研判 → 保守建议 → 通知留痕
   （可写设备：L2 默认 / L3 白名单仅增氧）       （只读信号 + 软件辅助；不碰硬联锁）
```

## 2. 共用底座技术设计

### 2.1 数据接入统一适配层（COMMON-INT-001）

| 数据模式 | 用途 | 当前状态 |
|---|---|---|
| Mock | 单元测试与开发联调 | 可立即实现 |
| Replay | 历史回放包（≥24h 带时间戳样本，交接项 A-01/A-03） | 待甲方样本；先用自造回放包 |
| Simulator | 设备仿真（控制柜/门禁/气体），分钟级生成 | 可立即实现（T2 轨核心） |
| Real | 只读接口接入 | ⛔ 等 E1/E2 证据，接口预留 |

- 统一输出格式：时序点（`point_id, ts, value, quality`）、事件、图像帧三类；
- **每条数据携带 `source_mode` 标签**，前端与审计日志强制显示"真实/回放/模拟"；
- 降级规则：Real 超时或心跳丢失 → 自动切 Replay/Simulator 并在界面标注。

### 2.2 Agent 决策编排中枢（COMMON-AGT-001/003）

- LLM 承担**综合研判与任务编排**，专业判断交给专业模型（时序检测、CV），Agent 不越权替代；
- Tool Calling 封装五类工具：`read_timeseries` / `read_event` / `read_video_frame` / `actuate_device`（仅通道 A）/ `notify_person`（B+）；
- 输出统一为结构化决策 JSON + 自然语言说明（NFR-002）：风险等级、判断依据、引用数据、命中规则、建议动作；
- 私有化 vs API：待甲方预算确认（`11_落点` §7-2）；Demo 默认按 API 快速验证 + 预留私有化替换层。

### 2.3 Safety Rule Engine（COMMON-SAF-001/002/003）

- 校验顺序：权限（模块 × 自动化等级白名单）→ 数据可信度 → 设备状态 → 合规规则 → 放行/拒绝/降级；
- **Fail-Closed**：引擎自身故障时拒绝一切执行动作（PRD §9.4.1）；
- 强制降级触发源：数据缺失、可信度低于阈值、设备离线、信号漂移、接口超时（COMMON-SAF-003 五类负例）；
- 模块隔离：渔业策略文件与粮库策略文件独立加载，互不影响（SAF-002）；
- 全部校验结果写入只读归档审计日志（NFR-001），含通道 B 独立触发留痕。

### 2.4 SLA 与超时降级（COMMON-NFR-003）

| 场景 | 提案阈值（待深度调研冻结） | 超时行为 |
|---|---|---|
| 渔业低氧研判 | 分钟级（如 ≤120s） | 降级 L1 建议 + 通知责任人 |
| 粮库熏蒸研判 | 小时级 | 同上 |
| 安防类事件 | 秒级（如 ≤10s） | 同上 |

## 3. 场景 A · 夜间溶氧骤降预警与增氧联动（主落点）

### 3.1 能力链路

```text
① 数据输入：DO/pH/水温 分钟级（Replay/Simulator）＋ 气象（公开数据替代，V-23）
② 专业模型 FISH-ALG-001：统计基线（时段均值±kσ）＋ 下降趋势斜率规则 → 低氧风险概率
③ Agent FISH-AGT-001：融合趋势/天气/塘口状态 → 风险等级 + 增氧策略（设备/时长/组合）
④ Safety Rule 校验：COMMON-SAF-001/003（可信度、设备状态、L2 权限）
⑤ 执行 FISH-INT-001：Simulator 控制柜下发启停 → 回读状态确认
⑥ 收尾：AGT-006 记录 L2/L3 决策路径 → 审计日志 + 可解释说明 → 看板展示
```

### 3.2 关键技术点

- **异常检测分级实现**：W2 先上规则基线（可解释、零训练成本）；W4 后叠加时序模型（如季节性分解 + 轻量预测）提升提前量，但**验收口径仍是"闭环能力"而非预测精度承诺**；
- **自动化等级演示**：默认 L2（策略生成后自动执行受控动作）；白名单环境演示 L3（仅增氧设备）；每次等级切换留痕；
- **回放案例集**：预置 ≥3 类夜间骤降剧本（缓降/骤降/波动下降），用于验收复现（对应 PRD §10.4 图 3/图 8 口径）；
- **降级演示**：拔掉模拟传感器数据流 → 系统应阻断增氧动作并转 L1 人工建议（负例必测）。

### 3.3 验收映射

| PRD 黄金模板 | 本方案对应 |
|---|---|
| §10.4 场景 A 验收 | 回放案例正确触发 + 场景 SLA 内结构化判断 + Simulator 下发与回读 + 审计可回溯 |

## 4. 场景 B · 熏蒸期人员误入告警与安全联动（并行·双态）

### 4.1 双态设计

| 态 | 触发条件 | 数据来源 | 演示口径 |
|---|---|---|---|
| **态 2（当前默认）** | Q1 未证 / 无现场证据 | 门禁/气体 Simulator + 录播视频样本 | 全语义可演示，界面显著标注"模拟" |
| **态 1（条件切换）** | W6 D-Q1：Q1 有硬联锁结论 | 真实门禁/气体状态信号（只读）+ RTSP 样例 | 真实只读验证 + B+ 软件辅助 |

### 4.2 能力链路（两态同构，仅数据源不同）

```text
① 输入：门禁/熏蒸/气体状态信号（I，只读）＋ 视频流（B+ 输入，不进通道 B）
② GRAN-ALG-001：CV 人员检测 + 区域识别（录播视频离线识别先行）
③ GRAN-AGT-001：融合门禁状态 + 熏蒸状态 + CV 结果 → L1 风险研判
④ GRAN-SAF-002：关键输入缺失（如视频不可用）→ 自动转入更保守策略
⑤ GRAN-AGT-008：生成处置建议（说明/通知/流程），经 Safety Rule 校验
⑥ B+ 输出：责任人通知 + 软件审计留痕（COMMON-SAF-001 B+ 通道）
⑦ 通道 B：原硬联锁独立运行，AI 不新增、不修改、不控制——演示中明确展示这一边界
```

### 4.3 关键技术点

- **CV 分级实现**：先用人形检测开源模型对录播样本做离线识别（准确率可控）；态 1 切换后再接实时流做在线推理；
- **保守策略逻辑**：任一关键输入缺失/超时 → 输出级别提高一档并立即通知（宁可误报，不可漏报）；
- **知识占位**：企业 SOP 未提供时，用 K-04 `[行业共性]` 作业守则占位并在输出中显式标注来源等级；
- **负例必测**：视频断流、门禁信号漂移、CV 低置信度三种情况下系统必须降级且不得输出"安全"结论。

### 4.4 验收映射

| PRD 黄金模板 | 本方案对应 |
|---|---|
| §10.5 场景 B 验收 | 态 2 全语义演示 + 缺输入更保守行为 + B+ 通知留痕 + 通道 B 独立性说明（图 6/图 8 口径） |

## 5. 技术选型建议（工作版，预算确认后冻结）

| 层 | 选型建议 | 备选 | 说明 |
|---|---|---|---|
| LLM | 国产大模型 API（快速验证） | 私有化部署（Qwen/GLM 系） | 待 `11_落点` §7-2 预算确认 |
| Agent 框架 | 成熟开源框架（函数调用 + 编排） | 自研轻量编排 | 以 Tool Calling 与审计友好为先 |
| 时序检测 | 统计基线 + 规则引擎先行 | 季节性分解/轻量预测模型 | 分级演进，验收不依赖精度 |
| CV | 开源人形检测模型 | 云端视觉 API | 录播离线先行，实时后置 |
| 数据层 | 轻量时序库 + 对象存储 | — | 满足分钟级时序与视频样本即可 |
| 演示层 | Web 看板（实时曲线 + 决策卡片 + 审计视图 + "模拟/真实"角标） | — | 可解释输出的主要载体 |

## 7. 降级路径矩阵（对齐 `12_数据交接清单.md`）

| 交接项 | 理想态 | 降级态（本方案默认） |
|---|---|---|
| A-01 水质数据流 | 真实点位表 + 样本 | 自造回放包 + Simulator 分钟级模拟 |
| A-02 控制柜接口 | 只读回读账号 | Device Simulator（L2 默认） |
| A-03 溯源历史数据 | 只读 API + 字段字典 | 脱敏 CSV + Mock 适配层 |
| A-04 气象接入 | 甲方字段说明 | 公开气象数据替代 |
| B-01 门禁/气体信号 | Q1 结论 + 只读点位表 | 独立 PLC/门禁 Simulator（态 2 默认） |
| B-02 视频流 | RTSP 地址样例 | 录播视频样本 + 离线识别 |
| C-01～C-04 授权知识 | 书面确认 + SOP | 全 Simulator + 行业共性守则占位标注 |

> 结论：**本方案在零证据状态下即可全量开工**；每一项真实证据到位后按 §7 逐格右移升级，不阻塞 Demo 主线。
