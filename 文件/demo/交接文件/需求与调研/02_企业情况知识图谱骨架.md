# 企业情况知识图谱骨架

> **状态**：Active · 渐进更新中  
> **目的**：用最小可维护结构记录“企业情况”的节点、关系、证据等级与待验证项。  
> **关联**：第二、三轮调研会回来填充和校对。

## 1. 节点分类

| 类型 | 含义 | 示例 |
|---|---|---|
| 组织节点 | 部门、角色、责任人 | 现场负责人、设备运维、政府对接人 |
| 系统节点 | 业务/物联网/数据/安全系统 | 渔业溯源、粮库一卡通、视频安防 |
| 设备节点 | 传感器/控制器/网关/PLC | DO 传感器、智能控制柜、门禁 PLC |
| 数据节点 | 关键字段/字段表/接口契约 | DO、pH、水温、仓内温湿度 |
| 痛点节点 | 现状 + 触发 + 影响 | 夜间溶氧骤降、熏蒸期误入 |
| 知识节点 | SOP / 病例 / 处置预案 | 病害 SOP、应急处置预案 |
| 合规节点 | 政府/监管/保密 | 县级储备粮监管字段 |
| 价值节点 | Demo 想证明的事 | 闭环能力、安全独立、决策可解释 |
