# 数据与接口现状猜测

> **状态**：Active · 渐进更新中  
> **目的**：在没有真实接口文档前，把可推测的接口、数据、权限现状写成一张表，作为后续资料请求和降级方案的输入。  
> **规则**：所有结论都标注 `[猜测]`，并指明依赖的证据闸门。

## 1. 业务系统猜测画像

| 系统 | 推测接口类型 | 推测字段 | 推测权限 | 证据 |
|---|---|---|---|---|
| 渔业溯源系统 | DB 直连 / API / 文件 / SDK | 水质、设备状态、告警、台账 | 只读优先，写入需明确授权 | E3 |
| 粮库一卡通系统 | DB 直连 / API / 文件 | 仓房、库存、出入库、监管字段 | 只读优先 | E3 |
| 视频安防平台 | RTSP / RTMP / SDK | 实时流、回放、事件 | 只读 | E3 |

## 2. 设备接口猜测画像

| 设备 | 推测协议 | 推测权限 | 风险点 |
|---|---|---|---|
| DO/pH/水温 | Modbus / 4–20 mA / SDI-12 | 只读 | 在线率与漂移 |
| 食台摄像头 | RTSP / ONVIF / SDK | 只读 | 夜视与存储周期 |
| 智能控制柜 | PLC（西门子 / 三菱 / 欧姆龙） / Modbus / OPC | 需授权 | 写权限边界、紧急停机 |
| 索道移动料仓 | 私有协议 / PLC | 需授权 | 任务协议与急停 |
| 分层温湿度 | 485 / Modbus / LoRa | 只读 | 老旧仓房漂移 |
| 通风窗/风机/气调 | PLC / Modbus / 私有 | 需授权 | 联锁、人工旁路 |
| 地磅 / RFID | RS-232 / TCP / API | 事件推送 | 重复事件与库存关联 |
| 门禁 / 熏蒸 / 气体 | 原系统硬联锁 / PLC | 原系统独立 | 不依赖 AI，独立触发 |

| 数据 | 推测来源 | 推测频率 | 推测问题 |

## 4. 降级方案猜测

| 不能获取 | 临时替代 | 说明 |
|---|---|---|
| DO 真实流 | 公开水产数据 + 自造分钟级样例 | 显式标注非真实 |
| 智能控制柜 | Device Simulator | 写入只发生在沙箱 |
| 索道调度 | 离线任务规划 + Simulator 回放 | 不做真实下发 |
| 分层温湿度 | 历史回放 + 可信度标记 | 用于离线机理/趋势模型 |
| 通风/气调控制 | 控制 Simulator + 人工旁路演示 | 不做真实下发 |
| 出入库业务 | 脱敏 CSV/事件文件 + Mock 主数据 | 不接入正式库存 |
| 视频流 | 录播样本 + B+ 识别 | 不进入通道 B |
| 监管字段 | 字段映射草案 + 内部 Demo | 不真实报送 |

## 5. 与“通道 B 独立性”相关猜测

- 门禁 / 熏蒸 / 气体 三类现场信号很可能属于原硬安全链路；
- 在 Demo 阶段不应让 AI 写入或替代这些信号；
- 若现场没有独立 PLC，必须引入独立 PLC 或仿真器，避免把 Simulator 当作真实硬联锁。
