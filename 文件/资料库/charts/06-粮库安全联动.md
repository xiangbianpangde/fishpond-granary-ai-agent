## 关键读点（v0.3.2 重写 · B 纯化）

### 两条真正独立的通道

- **通道 B：原有硬安全（完全独立）**——**只接收现场已有信号**。
  - 熏蒸状态、门禁状态、气体浓度和设备异常，均假定来自现场已有传感器。
  - → **原系统硬联锁** → **拒绝入场、应急逃生、声光告警**（仅依靠 PLC 或门禁系统自身能力）。
  - **Demo 新增的软件视觉识别不进入 B**。
  - 即使智能体完全失效、安全规则引擎完全故障，通道 B 仍应独立完成核心安全动作。
- **通道 B+：软件辅助（依赖安全规则引擎）**——只做软件补充。
  - 软件视频和视觉识别（不作为 B 的输入）→ 安全规则引擎 → **通知责任人、留下软件审计记录**。
  - 安全规则引擎只读通道 B 的事件镜像，用于审计。
  - 智能体只做 **L1 解释、研判、汇总和留痕**。

### 关键原则

- **原系统硬安全联锁独立运行，AI 不得绕过**。
- **安全规则引擎故障不得阻止原系统硬安全动作**。
- **安全规则引擎故障时，通道 A 必须停止执行并退回人工处理**（详见 PRD §9.4.1）。
- **通道 B 的安全动作不计入智能体自动化等级 L0–L4**，因为它属于独立系统行为。
- 原硬联锁的具体联动规则受**甲方安全 SOP**约束，仍待冻结。

### B 输入约束（下一轮深度调研必须核验）

| 输入类型 | 是否进 B | 依据 |
|---|---|---|
| 熏蒸状态（现场 PLC / 传感器） | ✅ 进 B | 假定为现场已有 |
| 门禁状态（现场硬信号） | ✅ 进 B | 假定为现场已有 |
| 气体浓度（现场 PLC） | ✅ 进 B | 假定为现场已有 |
| 设备异常（现场 PLC） | ✅ 进 B | 假定为现场已有 |
| **Demo 新增的视频/视觉识别** | ❌ **不进 B** | 不是现场已有信号，只用于 B+ 风险识别 |
| 智能体 L1 解释 | ❌ 不进 B | 只做说明，不触发硬安全动作 |
