## 关键语义规则（v0.3.3 全表统一）

1. **B 列定义**：只有“原硬安全联锁”使用 B 输入 / B 输出。**B 只代表原硬安全通道**，不代表所有设备执行。
2. **A 业务执行输出**：增氧机启停、索道调度、通风气调和车辆调度等普通业务动作归入此列，**不属于 B**。
3. **待现场核验**：涉及是否属于原硬联锁时，核验前在 B 输入列写“待现场核验；未核验前不计为 B 输入”，避免提前假设。
4. **新增 Demo 接口不等于 B 接口**：Demo 新增接口只能进入 A / B+，不能进入 B。

## 收敛与硬约束

- Demo 最终选择 **2–3 个场景**；
- 优先从两个**黄金参考场景**（夜间低氧 + 熏蒸误入）中选择；
- 其他场景作为**潜力场景**进入 Pilot 候选池；
- **承接率要求**（参见 PRD §10.6）：
  - Demo 达标 ≥ 60%
  - Stretch ≥ 80%
  - 危险动作错误放行 = **0**(冻结 Demo 安全负例测试集内)
  - 安全负例阻断 = **100%**(冻结 Demo 安全负例测试集内)
