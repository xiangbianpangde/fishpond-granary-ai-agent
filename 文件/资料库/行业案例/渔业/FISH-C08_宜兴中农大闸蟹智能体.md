# FISH-C08 宜兴中农 · 中国大闸蟹多模态“智能体”

> 证据：宜兴市政府 / 无锡市政府报道。**不是甲方现场事实。**  
> 上级索引：[[00_案例索引]]

## 主体

江苏中农物联网科技 + 农业农村部大数据发展中心；2024-12-16 宜兴市政府转载《宜兴日报》。2025-08 无锡市政府报道鹏鹞生态园 1000 亩数字化改造，并完成水产数据产品交易（材料自称 82.68 万元）。

## 能力

- 河蟹养殖智能问答（导入农牧学院习题/考卷）。
- 溶解氧预测（材料称 24 小时内）。
- 按密度/营养/饲料成分计算投喂时间与次数。
- 产地识别（阳澄湖 vs 非阳澄湖二分类材料自称 95%+）。
- IoT 数据卖给市农业农村大数据平台。

## 对本项目

- 行业已出现 **“螃蟹智能体”** 叙事，但公开能力是 **问答 + 预测 + 投喂方案生成 + 溯源**，不是 Safety Rule / 通道隔离 / 审计闭环。
- “24 小时溶氧预测”与 PRD 已降级的 P2 表述同构，**不得写入 Demo 硬验收**。
- 产地识别、数据交易与本 Demo 无关。

FISH-AGT-003（RAG 问答可参考形态）、FISH-SCN-002（投喂方案生成 = L1）、FISH-ALG-001（预测属 P2）
