# 行业案例索引 · Stage 2

> **范围**：空天渔场（智慧渔业 / 河蟹塘）与无人化粮库（储备粮 / 绿色储粮）两类公开案例。  
> **证据规则**：本目录全部为 **E4 行业公开资料**，不得写成甲方现场事实。对本项目的映射一律标 `[行业共性]` 或 `[可对照]`。  
> **用途**：对照 Demo 黄金场景 A（夜间低氧）和 B（熏蒸误入 / 粮情研判），提取可复用能力与不可照搬边界。  
> **存放规则**：**每个案例一张独立文件**，渔业在 `渔业/`，粮库在 `粮库/`。`01` / `02` 只作模块索引，不再堆案例正文。
