# GRAN-C11 标准与安全规程包（不是单个库）

> 证据：国标 / 行标 / 行业守则。**不是甲方现场事实。**  
> 上级索引：[[00_案例索引]]

## 标准/规程

| 标准/规程 | 与 Demo 的关系 |
|---|---|
| **GB/T 26882.1-2024**《粮油储藏粮情测控系统 第1部分：通则》2024-11-28 发布、2025-06-01 实施，代替 2011 版 | 粮情测控系统组成/验收的现行国标；现场 Q2 应问是否按 2024 版验收 |
| **LS/T 1813-2017** 数字测温电缆；**LS/T 1812-2017** 粮情测控信息交换接口 | 电缆与软件接口分册；COMMON-INT-001 / GRAN-DAT-001 对照 |
| 工程常用布置（2011 版实施口径，多份设计文件沿用）：平房仓测温电缆 **水平间距 ≤5m、垂直点距 ≤2m**，四周点在粮面下/靠墙/地坪约 30cm | 与 [[GRAN-C02_武汉五里粮库]]“<5m / <2m”一致；**2024 版正文间距未在本轮全文核出**，现场以甲方竣工图为准 |
| **LS/T 1225-2022** 氮气气调储粮技术规程 | 含安全要求；气调仓是有限空间，进仓必须测氧 |
| **LS/T 1226-2022** 粮库智能通风控制系统 | 通风是工艺自动/规则闭环，不是 Agent 改参数 |
| **LS/T 1213-2022** 二氧化碳气调 | 与氮气并列的免熏蒸路径 |
| 《粮库安全生产守则》（行业沿用文本）：磷化氢熏蒸及散气期间仓外警戒；氧气 **<19.5%** 或磷化氢高于限值须呼吸器；严禁向有限空间充氧 | 通道 B 的法规底线；Agent 不得放宽 |

## 对本项目

Q2/Q4 清单应带上标准号；Scene B 的“更保守策略”（GRAN-SAF-002）有法规依据：缺测气数据时不得开门、不得当正常仓。

## 需求对照

GRAN-DAT-001、GRAN-SAF-002、GRAN-SCN-003、COMMON-INT-001
